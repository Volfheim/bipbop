# bipbop

[English](README.md) · **Русский**

**Неподдерживаемый эксперимент с VPN для Android**, также известный как Volfheim VPN / Bip-Bop. Репозиторий сохранён для истории. Это не поддерживаемый сейчас продукт; прежние заявления о полной стабильности и готовности к эксплуатации не следует считать актуальными гарантиями.

## Содержимое

- `bipbop-android/` — интерфейс Flutter и интеграция с Android.
- `bipbop-engine/` — ядро Go и код нативной интеграции.
- Исторические коммиты, теги, файлы сборки и эксперименты.

В проекте исследовались интерфейс Flutter/Dart, Kotlin `VpnService`, связка JNI/CGO и сетевая часть на Go. Сборка и работа программы не перепроверялись в рамках этого обновления документации.

[Исходное историческое описание и заметки о сборке](docs/HISTORICAL_README.ru.md) · [Документация ядра](bipbop-engine/README.md)

Историческая документация сохранена как запись разработки и может содержать устаревшие инструкции. Поддерживаемые проекты для Windows представлены в [моём профиле](https://github.com/Volfheim).
